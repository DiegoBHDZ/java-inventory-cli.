# Inventory Management System (CLI)

Sistema de gestión de inventario basado en consola, desarrollado en Java aplicando Programación Orientada a Objetos (POO) y persistencia de datos.

## Características
- **CRUD Completo:** Agregar y Listar productos.
- **Persistencia de Datos:** Los productos se guardan automáticamente en un archivo CSV (`inventario.csv`), evitando la pérdida de datos al cerrar la aplicación.
- **Arquitectura en Capas:** Separación clara entre la Lógica de Negocio (`InventarioService`), el Modelo (`Producto`) y la Interfaz de Usuario (`App`).

## Tecnologías Utilizadas
- **Java SE** (Backend Logic)
- **Java I/O** (FileWriter, BufferedWriter, Scanner para manejo de archivos)
- **Git** (Control de versiones)

## Cómo Ejecutar
1. Clonar el repositorio.
2. Abrir la carpeta en VS Code o IntelliJ.
3. Ejecutar el archivo `src/app/App.java`.
4. Seguir las instrucciones del menú en consola.
